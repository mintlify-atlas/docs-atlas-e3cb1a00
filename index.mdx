CubeSandbox is a high-performance, open-source sandbox service that lets AI agents execute code in fully isolated, hardware-level environments. Built on KVM MicroVMs and RustVMM, it delivers sub-60ms cold starts, less than 5MB per-instance memory overhead, and a drop-in replacement for the E2B SDK — all deployable on your own infrastructure.

## Why CubeSandbox?

CubeSandbox was built to solve the fundamental tension between security and performance in AI agent code execution.

<CardGroup cols={2}>
  <Card title="Sub-60ms cold start" icon="bolt">
    Resource pool pre-provisioning and snapshot cloning skip all cold-start overhead. Average end-to-end time is under 60ms at single concurrency, under 150ms at 50 concurrent creations.
  </Card>
  <Card title="True kernel isolation" icon="shield-halved">
    Each sandbox runs a dedicated OS kernel in its own MicroVM. No shared-kernel container escapes — every agent is fully isolated at the hardware level.
  </Card>
  <Card title="E2B SDK compatible" icon="plug">
    Drop in as a replacement for E2B Cloud. Change one environment variable (`E2B_API_URL`) and your existing SDK code runs unchanged against your own infrastructure.
  </Card>
  <Card title="High-density deployment" icon="server">
    Under 5MB memory overhead per sandbox via CoW technology and an aggressively trimmed Rust runtime. Run thousands of agents on a single machine.
  </Card>
  <Card title="eBPF network security" icon="network-wired">
    CubeVS enforces per-sandbox network policies entirely in kernel space using eBPF, with CIDR-based egress filtering and strict inter-sandbox isolation.
  </Card>
  <Card title="Single and multi-node" icon="sitemap">
    One-click installer supports both standalone single-node deployments and horizontal scale-out to multi-node clusters.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Prepare your environment">
    CubeSandbox requires a KVM-enabled x86_64 Linux host. Use WSL 2, a Linux physical machine, or a cloud bare-metal server. See [Dev Environment](/dev-environment) for using a disposable QEMU VM.
  </Step>
  <Step title="Install CubeSandbox">
    Run the one-click installer inside your Linux environment:
    ```bash
    curl -sL https://github.com/tencentcloud/CubeSandbox/raw/master/deploy/one-click/online-install.sh | bash
    ```
  </Step>
  <Step title="Create a template">
    Build a sandbox template from the prebuilt code-interpreter image using `cubemastercli`. See [Quickstart](/quickstart) for the full command.
  </Step>
  <Step title="Run your first agent">
    Install `e2b-code-interpreter`, point `E2B_API_URL` at your local instance, and run code in an isolated sandbox using the standard E2B SDK.
  </Step>
</Steps>
